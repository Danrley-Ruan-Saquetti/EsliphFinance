# Requisitos não funcionais

## RNF-0001 — O sistema deve ser feito para plataforma mobile.

- **status:** active

## RNF-0002 — O sistema deve possuir um backend responsável pelas regras de negócio e pela persistência dos dados.

- **status:** active

## RNF-0003 — O banco de dados deve ser armazenado em nuvem.

- **status:** active

## RNF-0004 — Os valores monetários devem ser armazenados como números inteiros, em centavos, com precisão de 2 casas decimais na exibição.

- **status:** active

## RNF-0005 — A autenticação deve ser realizada por meio de token JWT.

- **status:** active

## RNF-0006 — As senhas devem ser armazenadas com algoritmo de hash irreversível.

- **status:** active

## RNF-0007 — A comunicação entre o aplicativo e o backend deve ocorrer por HTTPS.

- **status:** active

## RNF-0008 — Operações que afetam o saldo de mais de uma _Conta_ simultaneamente devem ser atômicas, garantindo que nenhuma _Conta_ fique com o saldo inconsistente em caso de falha.

- **status:** active
